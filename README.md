# 💱 Conversor de Moedas para BRL

> Aplicação CLI em Python que consulta cotações em tempo real e converte moedas estrangeiras para o Real Brasileiro (BRL).

## 📌 Sobre o Projeto

Aplicação desenvolvida como parte do BootCamp - Etapa Intermediária. Conecta-se à AwesomeAPI para buscar cotações em tempo real e converte USD, EUR, GBP, BTC e ARS para o Real.

## 🚀 Como Executar

```bash
pip install -r requirements.txt
python main.py
```

## 🧪 Testes

```bash
python -m pytest test_integracao.py -v
```

## 🌐 API Utilizada

AwesomeAPI — https://docs.awesomeapi.com.br/api-de-moedas
Gratuita, sem necessidade de chave de acesso.
